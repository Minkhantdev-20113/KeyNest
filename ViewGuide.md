# KeyNest View Guide

KeyNest သည် Firebase account ဖြင့် ဝင်ရောက်ပြီး ကိုယ်ပိုင် API keys များကို Firestore တွင် စီမံပါသည်။

- Dashboard: key count နှင့် provider breakdown
- API Keys: create, edit, delete, search, filter, and test
- Settings: username၊ password နှင့် initial avatar စာလုံး/color
- Sidebar: Firebase refresh status နှင့် logout

Firebase configuration မရှိသေးပါက `.env.example` နှင့် [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md) ကို အသုံးပြုပါ။
